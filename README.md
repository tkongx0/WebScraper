# WebScraper
**Custom script written in Python to extract contents from a blog into WordPress blogs.**

Uses selenium to emulate a chrome webdriver (requires downloading the chrome web driver). Then uses BeautifulSoup to find and scrape specific contents based on html elements. Pushes data via WP backend API into "block" mode

**Programming Language / Libraries:**
- [Python](https://www.python.org/) 
- [Dependacies]
	- [Selenium](https://pypi.org/project/selenium/)
  - [BeautifulSoup](https://pypi.org/project/BeautifulSoup/)

## Getting Started

- Install any Python version from 3.10 and up
- Install dependencie(s) `pip install`
- Enviornemt variables are in possibly needed. Either construct a config.py file, env file or manually input env variables (not recommended other than for testing)
- Run `main.py` within your chosen IDE
